# Classifying-News-Articles Project-
📰 News Article Classification A machine learning project that automatically classifies news headlines into 5 categories — Politics, Sports, Business, Wellness, and Parenting — using the HuffPost news dataset.
Compares two approaches: TF-IDF + Logistic Regression vs. LSTM (Deep Learning)
Best model: Logistic Regression achieved 70.86% accuracy, outperforming LSTM (46.33%) on this limited dataset
Includes text preprocessing (tokenization, stopword removal, lemmatization), word cloud visualizations, and a confusion matrix comparison
Deployed as an interactive Streamlit web app for real-time headline classification

🛠️ Tech Stack
Python · scikit-learn · TensorFlow/Keras · NLTK · TF-IDF · Streamlit · Matplotlib · Seaborn
